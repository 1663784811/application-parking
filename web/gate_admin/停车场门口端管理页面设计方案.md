# 停车场门口端管理页面设计方案
本设计方案针对停车场门口端管理场景，面向停车场值守人员、安保人员设计，
聚焦车辆进出管控、现场应急处理、设备状态监控等核心需求，适配门口岗亭 PC 端（1920×1080分辨率），
兼顾操作便捷性与信息直观性，确保值守人员快速响应各类现场情况。

# 一、核心页面详细设计
## 1.1 登录页面
卡片白色底色，带投影效果，居中展示，包含以下内容：
- 系统标题：展示「停车场管理系统」大字标题，搭配车辆图标，明确系统用途
- 账号输入框：提示文字「请输入保安账号」，必填项，支持纯数字、账号字符输入
- 密码输入框：提示文字「请输入密码」，必填项，密码隐藏显示
- 记住账号选项：复选框组件，勾选后本地缓存账号，下次登录自动填充
- 登录按钮：通栏主色按钮，醒目突出，为页面核心操作按钮

## 1.2 首页（默认页面）
### 1.2.1道闸实时监控 （ 左上 ）
首页核心置顶模块，支持多道闸全景实时监控，覆盖停车场所有出入口设备，实现设备状态可视化值守。
- 展示所有道闸设备编号、安装位置、设备名称，区分主入口、主出口、地下车库、应急通道等不同道闸。
- 实时展示道闸在线/离线、正常/故障、开启/关闭运行状态，通过色彩标识直观区分设备工况。
- 实时刷新道闸运行姿态，监控闸杆起落状态，识别卡顿、异常悬停等机械故障。
- 设备异常自动高亮预警，提醒保安及时排查、报修，规避通行安全隐患。

### 1.2.2车辆通行记录（ 左下 ）
按时间倒序排列，优先展示最近通行记录，方便保安实时核对出入口通行情况
- 核心展示字段：通行时间、车牌号码、通行道闸、进出类型、车辆状态。
- 数据自动实时刷新，车辆完成通行后即刻更新记录，无需手动刷新页面。


### 1.2.3车辆通行图片（ 右上 ）
关联道闸摄像头抓拍数据，展示当前/最新通行车辆抓拍图片，实现车牌可视化核验
- 车辆经过道闸时系统自动抓拍车头图片，在首页对应模块展示。
- 支持图片实时预览，保安可对照抓拍图片核验车牌、车辆外观，排查无牌车、套牌车、违规车辆。
- 图片与通行记录一一对应，实现「一条记录+一张抓拍图」的溯源模式。
- 进场2张图片，出场2张图片

### 1.2.4车辆通行信息（ 右上 ）
- 基础信息：车牌号码、车辆类型、入场/出场类型、对应出入口道闸。
- 时间信息：通行具体时间、在场时长（出场车辆展示）。
- 状态信息：正常通行、拦截失败、异常通行、人工放行等通行状态。
- 计费详情：系统自动展示车辆本次停车计费核心数据，包含计费单价、免费时长、抵扣时长、应付金额、实付金额、计费状态（待支付/已支付/免费放行）


### 1.2.5道闸操作（ 右下 ）
首页远程应急操控模块，支持保安对各出入口道闸进行远程手动控制，适配特殊值守场景。
- 查看应缴费用：联动车辆计费详情数据，保安可一键查看当前出场车辆的全部计费信息，包含停放时长、计费规则、应付费用，快速核对停车账单，为现场收费放行提供数据依据。
- 现金支付结算：针对车主现场现金缴费场景，提供人工结算操作入口。保安录入实收现金金额后，系统完成账单核销、更新计费状态为「已支付」，留存现金缴费记录，保证账目可追溯。
