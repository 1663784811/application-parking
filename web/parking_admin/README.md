停车场后台管理系统页面完整设计方案
## 一、整体定位与设计规范
### 1. 系统定位
   面向停车场管理员、运营、财务使用的 B 端管理后台，功能覆盖车场管理、车辆进出、收费、设备、会员、报表、系统设置，适配 PC 端 1920/1440 分辨率，支持多车场统一管理。

### 2. 视觉规范
   （1）色彩体系
   主色：#165DFF（科技蓝，按钮、导航、高亮数据）
   辅助色：#00B42A（通行成功）、#F53F3F（异常 / 欠费）、#FF7D00（临时车 / 预警）
   中性色：#1D2129（标题）、#4E5969（正文）、#86909C（次要文字）、#F2F3F5（页面背景）、#FFFFFF（卡片底色）

   （2）字体规范
   标题：16–20px 加粗
   正文：14px 常规
   辅助说明：12px
   统一字体：Inter / 微软雅黑

   （3）布局规则
   侧边固定导航 + 顶部操作栏 + 主内容区三栏经典 B 端布局；卡片圆角 6px，分割线 #E5E6EB，轻微阴影分层。

## 顶部顶部栏（高度 60px）
左侧：收起侧边栏按钮 + 当前页面面包屑
中间：全局搜索（车牌 / 订单号 / 车场名）
右侧：消息通知（设备故障、欠费提醒）、切换车场、管理员头像下拉（修改密码、退出登录）


## 中间主内容区域
自适应宽度，内容以卡片、表格、弹窗、图表组合，分页统一每页 10/20 条。
三、核心页面详细设计（共 8 大页面）
页面 1：工作台首页（数据仪表盘）
布局：顶部数据指标卡片 + 中部图表 + 下方快捷功能 + 实时通行
1. 顶部核心指标（4 张横向卡片）
   今日总营收：¥XXXX 环比昨日↑/↓X%
   当前在场车辆：XX 辆 / 总车位 XXX（车位利用率 XX%）
   今日进出车次：进场 XX 出场 XX
   待处理异常订单：XX 笔（欠费、无牌、道闸故障）
2. 中部图表区（左右分栏）
   左：折线图 近 7 日营收趋势（X 轴日期 Y 轴收入）
   右：柱状图 近 7 日车流量（进场 / 出场对比）
3. 下分区 1：车位状态可视化
   色块看板：绿色 = 空闲、蓝色 = 固定车占用、橙色 = 临时车、红色 = 故障车位，标注各状态数量。
4. 下分区 2：实时通行抓拍列表（滚动刷新）
   列表字段：抓拍图片、车牌、进场时间、通道、车辆类型、状态（正常 / 无牌 / 黑名单），支持一键查看详情、开闸放行。
5. 右下角快捷操作按钮
   新增车场、批量导出今日账单、设备巡检、批量月卡续费


## 页面 2：车场 & 车位管理页
   2.1 车场列表页面
   筛选栏
   车场名称、区域、运营状态（启用 / 停用）、搜索框
   操作按钮
   新增车场、批量启用 / 停用、导出车场信息
   表格字段
   车场 ID、车场名称、地址、总车位、空闲车位、联系管理员、创建时间、状态、操作（编辑 / 查看车位 / 删除）
   新增 / 编辑车场弹窗
   表单项：车场名称、省市区详细地址、总车位数量、联系人、联系电话、收费模板绑定、车场图片、启用开关
   2.2 车位管理子页面
   筛选：车场下拉、车位状态、车位类型（固定 / 临时 / 无障碍）
   可视化视图（两种切换：表格视图 / 平面图视图）
   平面图视图：模拟停车场平面图，每个车位方块标注编号 + 状态，点击弹窗分配车主 / 标记故障
   表格字段：车位编号、所属区域、车位类型、绑定车主、当前占用车辆、状态（空闲 / 占用 / 故障）、操作（分配 / 解绑 / 报修）
## 页面 3：车辆通行管理
   3.1 实时监控页面
   顶部通道切换：1 号入口、2 号出口、地下入口等
   实时视频窗口：摄像头实时画面，下方同步抓拍截图、识别车牌
   实时通行消息流：新进场车辆实时推送，异常车辆标红提醒
   应急操作：远程开闸、强制抬杆、拉黑车牌
   3.2 通行记录查询
   高级筛选
   时间段、车场、通道、车牌、车辆类型、进出类型、是否缴费、有无异常
   表格字段
   抓拍图、车牌、进场时间、出场时间、停留时长、通道、车辆类型、收费金额、状态、操作（查看完整记录、补费）
   批量功能：导出 Excel、批量打印小票
   3.3 异常通行记录
   单独筛选：无牌车辆、黑名单、超时滞留、逃费车辆，支持批量加入黑名单、短信通知车主补缴。
## 页面 4：收费管理（财务核心）
   4.1 收费流水订单
   筛选：时间、车场、车牌、支付方式（微信 / 支付宝 / 现金 / 月卡抵扣）、订单状态（待支付 / 已结清 / 退款）
   表格：订单号、车牌、进场时间、出场时间、应付金额、实付、优惠、支付渠道、操作员、操作（退款、重开发票）
   4.2 收费规则配置
   卡片表单配置收费标准：
   临时车：首小时费用、后续每小时、24 小时封顶价
   固定月卡：月 / 季 / 年定价，免费出场
   免费时长设置（商场消费减免）
   优惠规则：节假日折扣、优惠券抵扣上限
   4.3 对账 & 发票管理
   每日对账：车场日汇总营收、线上线下金额对比、差额标注
   发票列表：车主开票记录、抬头、税号、开票状态，支持批量冲红
   页面 5：会员月卡管理
## 5.1 固定车主列表
   筛选：车牌、手机号、卡状态（正常 / 过期 / 冻结）
   表格：车牌、车主姓名、手机号、卡类型（月 / 季 / 年）、到期时间、剩余天数、缴费记录、操作（续费、冻结、解绑、发送到期提醒）
   5.2 套餐配置
   新增套餐弹窗：套餐名称、有效期、售价、适用车场、赠送时长、是否自动续费
   5.3 续费记录
   所有充值、续费流水，可按车主 / 时间筛选导出。 

## 页面 6：设备管理
   设备总列表
   筛选：设备类型（道闸 / 摄像头 / 显示屏 / 地感）、车场、在线状态
   表格：设备编号、设备名称、安装通道、IP 地址、在线状态、最近故障时间、操作（远程重启、报修、编辑参数）
   设备故障模块
   故障工单列表：故障设备、上报时间、故障类型、处理人、处理状态，支持指派维修人员、填写维修记录。
## 页面 7：数据统计报表
   全部报表支持按日 / 周 / 月 / 自定义时间段筛选，一键导出 Excel/PDF
   营收统计报表：各车场收入、线上线下占比、优惠抵扣总额
   车流量报表：分时段进出车辆高峰分析
   车位利用率报表：每日平均空闲率、高峰拥堵时段
   月卡营收报表：固定车主续费收入统计
## 页面 8：系统权限设置
   管理员账号管理：新增操作员、分配车场权限、禁用账号
   角色管理：超级管理员 / 财务 / 车场值守 / 巡检员，自定义菜单权限
   系统日志：登录日志、操作日志（开闸、退款、修改收费规则）
   短信配置：到期提醒、欠费催缴短信模板设置

## 四、通用组件 & 交互设计规范
   弹窗：新增 / 编辑弹窗宽度 600–800px，底部确认 / 取消按钮；详情弹窗全屏侧边抽屉
   表格：支持单列筛选、排序、批量勾选操作
   状态标签
   通行正常：绿色标签
   欠费 / 异常：红色标签
   车位空闲：绿色、占用蓝色、故障灰色
   全局加载：接口请求居中加载动画；无数据空白状态插图提示
   消息提示：操作成功绿色 toast、失败红色提示；重要弹窗二次确认（删除、批量退款）
   权限控制：无权限菜单隐藏，按钮置灰不可点击
