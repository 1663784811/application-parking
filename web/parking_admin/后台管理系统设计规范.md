# 后台管理系统设计规范

> 适用项目：`parking_admin`（Vue 3 + Vite + view-ui-plus + less）
> 变量定义文件：`src/styles/variables.css`（由 `src/main.js` 全局引入，页面直接使用 CSS 变量）

本规范为通用后台管理系统的设计规范，所有色值、尺寸、间距均与 `src/styles/variables.css` 保持一致。新增页面请严格遵循，以保证视觉统一。

---

## 一、设计原则

| 原则 | 说明 |
| --- | --- |
| **克制中性** | 中性色（文本/背景/边框）占页面 80%+，主色仅用于关键操作与状态强调 |
| **统一主色** | 全局主色 `#165DFF`，传达专业、可信、科技感 |
| **一致语义** | 同一状态在表格、徽标、标签、图表中颜色含义一致 |
| **8 倍数节奏** | 间距、尺寸以 4 / 8 / 12 / 16 / 24 / 32 为基准，保证节奏感 |
| **少即是多** | 阴影克制、圆角统一、不滥用渐变，优先留白与对齐建立层次 |

## 二、颜色规范

### 2.1 主题色

| 用途 | 变量 | 色值 | 使用场景 |
| --- | --- | --- | --- |
| 主色 | `--primary-color` | `#165DFF` | 主按钮、选中态、链接、主数据 |
| 主色-hover | `--primary-hover-color` | `#4080FF` | 主按钮悬停 |
| 主色-active | `--primary-active-color` | `#0D47A1` | 主按钮按下 / 深色强调 |

### 2.2 功能色（成功 / 错误 / 警告）

| 语义 | 变量 | 主色 | hover | active | 使用场景 |
| --- | --- | --- | --- | --- | --- |
| 成功 | `--success-color` | `#00B42A` | `#23D130` | `#008F20` | 操作成功、正常状态 |
| 错误 | `--error-color` | `#F53F3F` | `#FF7875` | `#CB2A2A` | 删除、错误、校验失败 |
| 警告 | `--warning-color` | `#FF7D00` | `#FF9A3C` | `#CC6400` | 警告、提醒、待处理 |

### 2.4 状态标签色（Status Tag）

标签采用「主色 10% 透明度背景 + 主色文字」的统一公式：

| --- | --- | --- | --- |
| 主色 | `rgba(22, 93, 255, 0.1)` | `#165DFF` | `.status-tag--primary` |
| 成功 | `rgba(0, 180, 42, 0.1)` | `#00B42A` | `.status-tag--success` |
| 警告 | `rgba(255, 125, 0, 0.1)` | `#FF7D00` | `.status-tag--warning` |
| 错误 | `rgba(245, 63, 63, 0.1)` | `#F53F3F` | `.status-tag--error` |
| 默认 | `rgba(134, 144, 156, 0.1)` | `#86909C` | `.status-tag--default` |

## 三、字体规范

### 3.1 字体族

```css
font-family: 'Inter', 'Microsoft YaHei', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

- 英文/数字优先 `Inter`，中文回退 `Microsoft YaHei`（微软雅黑），再回退系统字体。
- 全局开启字体平滑：`-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;`

### 3.2 字号

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--font-size-xs` | `12px` | 标签、辅助说明、表格次要文字 |
| `--font-size-sm` | `14px` | **正文基准**（body 默认）、按钮、表单、表格 |
| `--font-size-md` | `16px` | 小标题、卡片标题、强调正文 |
| `--font-size-lg` | `20px` | 区域标题、统计数值 |
| `--font-size-xl` | `24px` | 页面主标题、大统计数值 |

> 特殊展示场景（如首屏主标题 `44px`、区块标题 `28px`）可按需脱离栅格，但仅限营销/首屏页。

### 3.3 字重

| 字重 | 用途 |
| --- | --- |
| `400` Regular | 正文、说明文字 |
| `600` Semibold | 卡片标题、统计数值、按钮文字 |
| `700` Bold | 页面/区域主标题、Logo |
| `800` Extrabold | 首屏 Hero 大标题（仅首屏） |

### 3.4 行高

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--line-height-sm` | `1.4` | 紧凑：标签、表格单元格 |
| `--line-height-base` | `1.5` | **默认**：正文、按钮、表单 |
| `--line-height-lg` | `1.75` | 宽松：多行描述、段落说明 |

## 四、间距规范

全局以 4 为基准步进，遵循 8 倍数节奏：

| 变量 | 值 | 典型用途 |
| --- | --- | --- |
| `--spacing-xs` | `4px` | 标签内距、图标与文字间距、极小留白 |
| `--spacing-sm` | `8px` | 组件内部小间距、表单项间距 |
| `--spacing-md` | `12px` | 筛选项 gap、布局内容区内边距 |
| `--spacing-lg` | `16px` | 卡片间距、筛选栏与表格间距 |
| `--spacing-xl` | `24px` | 卡片/筛选栏/表格容器内边距（**最常用**） |
| `--spacing-xxl` | `32px` | 区块间距、首屏留白 |

> **经验法则**：容器内边距统一用 `--spacing-xl`；同级卡片之间用 `--spacing-lg`；表单/筛选项之间用 `--spacing-md`。

## 六、阴影规范

阴影克制，仅用于浮起卡片与交互反馈，严禁滥用：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-light` | `0 1px 4px 0 rgba(0,0,0,0.04)` | 轻浮起：次要卡片 |
| `--shadow-base` | `0 2px 6px 0 rgba(0,0,0,0.06)` | **默认**：筛选栏、统计块、表格容器 |
| `--shadow-medium` | `0 4px 12px 0 rgba(0,0,0,0.08)` | hover 反馈：卡片悬停 |
| `--shadow-heavy` | `0 8px 24px 0 rgba(0,0,0,0.12)` | 弹窗、下拉浮层 |

## 七、布局规范

### 7.1 整体布局

后台采用「侧边栏 + 顶栏 + 内容区」结构（见 `MainLayout.vue`）：

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `--sider-width` | `240px` | 侧边栏展开宽度 |
| `--sider-collapsed-width` | `64px` | 侧边栏收起宽度 |
| `--header-height` | `60px` | 顶部栏高度 |

```
┌───────────────────────────────────────────────┐
│ Sider │           Header (60px)               │
│(240px)├───────────────────────────────────────┤
│       │  Content (padding: 12px, gap: 10px)   │
│       │ ┌──────────┬──────────────────────┐   │
│       │ │ 次级侧栏  │   router-view         │   │
│       │ │ (可选)    │   (主内容区)          │   │
│       │ │          │                       │   │
│       │ └──────────┴──────────────────────┘   │
└───────────────────────────────────────────────┘
```

- 内容区内边距：`--spacing-md`（12px），子区块间 gap：`10px`。
- 内容区背景：`--bg-color-page`。
- 主内容区 `flex: 1`，纵向排布，支持滚动。

### 7.2 容器宽度（首屏/营销页）

| 场景 | 最大宽度 |
| --- | --- |
| 首屏导航/容器 | `1080px`，水平居中，左右 padding `--spacing-xxl` |
| 首屏文案区 | `720px`，居中 |

### 7.3 栅格

- 统计卡片行：`grid-template-columns: repeat(5, 1fr)`，gap `--spacing-lg`。
- 功能卡片网格：`repeat(3, 1fr)`，gap `--spacing-lg`。
- 响应式断点 `@media (max-width: 768px)`：多列网格降为单列，首屏标题缩放、按钮纵向堆叠。

### 7.4 列表页标准结构

每个列表页自上而下四段：

1. **筛选栏 `.filter-bar`**：padding `--spacing-xl`，白底，圆角 base，阴影 base，下边距 `--spacing-lg`。
   - `.filter-row`：flex wrap，gap `--spacing-md`；输入框宽 `180px`，下拉 `150px`。所有筛选项与操作按钮均以 `.filter-item`（`flex-shrink: 0`）包裹，不再使用 `.filter-actions`。
2. **统计行 `.stats-row`**（可选）：grid，gap `--spacing-lg`，下边距 `--spacing-lg`。
   - `.stat-item`：padding `--spacing-xl`，白底，圆角 base，阴影 base，纵向 flex。
   - `.stat-label`：`--font-size-sm` / `--text-color-secondary` / 下边距 `--spacing-xs`。
   - `.stat-value`：`24px` / `600` / `--text-color-title`。
3. **表格容器 `.table-container`**：白底，圆角 base，padding `--spacing-xl`，阴影 base。
4. **分页 `.pagination-wrapper`**：flex，`justify-content: flex-end`，上边距 `--spacing-xl`。

## 八、组件规范

> 组件库为 **view-ui-plus**，以下为项目内的统一用法与封装约定。

### 8.1 按钮 Button

| 类型 | 用法 | 场景 |
| --- | --- | --- |
| `type="primary"` | 主操作 | 查询、新增、提交、确认 |
| 默认 | 次操作 | 重置、导出、取消 |
| `type="text" size="small"` | 行内操作 | 表格行内的查看/编辑/删除等 |
| `size="large"` | 强 CTA | 首屏主按钮 |

- 行内文字按钮统一 `type="text" size="small"`，危险操作可加 `.text-warning` / `.text-error`。
- 带图标按钮：图标在前，文字在后，如 `<Button type="primary"><Icon type="ios-add" />新增</Button>`。

### 8.2 表单与输入

- 输入框 `Input`：支持 `clearable`、`@on-enter` 触发查询；搜索框用 `#prefix` 插槽放 `ios-search` 图标。
- 下拉 `Select`：宽度统一 `150px`，输入框统一 `180px`（除非内容更长）。
- 输入框聚焦边框：`--border-hover-color`（`#165DFF`）。

### 8.3 表格 Table

- 列定义使用 `minWidth`（非固定 width），保证自适应：`{ title, key/slot, minWidth }`。
- 操作列固定右侧：`fixed: 'right'`，`minWidth: 220`。
- 数值列 `align: 'right'`，状态列 `align: 'center'`。
- 自定义单元格用 `slot`（如 `status`、`action`），复杂渲染可用 `render`。
- 状态展示用 `Badge`：`<Badge :status="..." :text="..." />`，状态映射：成功 `success`、进行中 `processing`、警告 `warning`、错误 `error`、默认 `default`。
- 加载态：`<Table :loading="state.loading">`。

### 8.4 状态标签 / 徽标

- 统一 `.status-tag`：`display: inline-flex; padding: 2px 8px; font-size: --font-size-xs; border-radius: --border-radius-sm`。
- 配色见 [2.4 状态标签色](#24-状态标签色status-tag)。
- 优先复用 `variables.css` 已定义的 `.status-tag--*` 与 `.text-*` 工具类。

### 8.5 卡片 Card

- 通用卡片类 `.card`：白底、圆角 base、阴影 base、padding `--spacing-xl`。
- 卡片标题 `.card-title`：`--font-size-md` / `600` / `--text-color-title` / 下边距 `--spacing-lg`。
- hover 交互：`transform: translateY(-4px)` + `--shadow-medium` + 边框加深，过渡 `0.25s ease`。

### 8.6 反馈 Modal / Message

- 二次确认用 `Modal.confirm({ title, content, onOk })`。
- 轻量提示用 `Message.success/info/error(...)`。
- 表单弹窗用 `Modal` + 自定义内容。

### 8.7 分页 Page

- `<Page :total :current :page-size show-total show-elevator @on-change />`，默认右对齐。

## 九、图标规范

- **首选** view-ui-plus 内置 Icon（基于 ionicons，字体在 `src/styles/fonts/`）。
- 常用图标：`ios-search` 搜索、`ios-add` 新增、`ios-download-outline` 导出、`ios-arrow-forward` 前进、`ios-eye` 查看、`ios-create` 编辑、`ios-trash` 删除、`ios-close` 关闭。
- 需自定义 SVG 时，抽取到资源目录统一管理，不在组件内内联散落。
- 图标尺寸随场景：表格行内 `16px`、卡片功能图标 `24px`、首屏强调 `22px`。

## 十、图片规范

- 图片比例统一采用：**1:1** / **3:4** / **9:16**。
- 图片资源置于 `public/` 或 `src/assets/`，按模块分目录。
- 需缩略图的场景用 CSS `object-fit: cover` 裁切。

## 十一、动效规范

| 场景 | 过渡 | 时长 |
| --- | --- | --- |
| 通用 hover / 状态切换 | `transition: all 0.25s ease` | 250ms |
| 卡片上浮 | `transform: translateY(-4px)` | 250ms |
| 箭头位移 | `transform: translateX(3px)` | 250ms |
| 阴影/边框变化 | 与上浮同步 | 250ms |

- 统一使用 `ease` 缓动，时长以 `0.25s` 为基准，避免过多不同时长造成混乱。
- 不使用持续循环的动画干扰数据阅读。

## 十二、数据图表规范（ECharts）

- 图表色板与功能色一致：主数据 `#165DFF`、成功 `#00B42A`、错误 `#F53F3F`、警告 `#FF7D00`，多系列可扩展紫 `#722ED1`、青 `#0FC6C2`。
- 坐标轴文字使用 `--text-color-secondary`（`#86909C`），轴线/网格用 `--border-color-light`（`#F2F3F5`）。
- Tooltip 背景白底 + `--shadow-medium`，圆角 base。
- 数值标签字号 `--font-size-xs`，避免与正文抢视觉。

## 十三、代码与命名规范

### 13.1 页面状态

所有页面响应式数据统一收敛进一个 `state`，便于维护：

```vue
<script setup>
import { reactive } from 'vue'
const state = reactive({})
</script>
```

### 13.2 路由

- **统一使用名称路由跳转**以保留 params：`router.push({ name: 'home' })`。
- 路由 name 与文件名对应（小写）：如 `Home.vue → home`。
- `@` 别名指向 `src` 目录。

### 13.3 样式

- 使用 **less**，保持层级嵌套结构，禁止平铺散写。
- **统一使用 `src/styles/variables.css` 中的 CSS 变量**，禁止在页面硬编码色值/尺寸（除首屏特殊展示场景）。
- **禁止使用 `@media :deep`**；需要穿透样式时改用 less 嵌套或合理的 class 命名。
- 局部样式加 `scoped`：`<style lang="less" scoped>`。
- 响应式断点统一 `@media (max-width: 768px)`。

### 13.4 class 命名

- BEM-lite 风格：块 `__` 元素、`--` 修饰符，或短横线连词（如 `.filter-bar`、`.filter-row`、`.stat-item`、`.stat-item.warning`）。
- 状态修饰用连字符：`.status-tag--success`、`.type-1`。

### 13.5 文件组织

```
src/
├── api/            # 接口（app.js / axiosRequest.js 禁止修改）
├── router/         # 路由
├── stores/         # Pinia
├── styles/
│   ├── variables.css   # 全局设计变量（本规范之源）
│   ├── viewuiplus.css  # 组件库样式覆盖
│   └── fonts/          # icon 字体
└── views/
    └── <模块>/<页面>/<页面>.vue   # 如 order/orderList/orderList.vue
```
