# 个人中心接口文档

## 通用响应格式

所有接口返回的通用响应格式如下：

```json
{
  "code": 2000,
  // 状态码
  "msg": "操作成功",
  // 提示信息
  "data": {},
  // 返回数据
  "result": null
  // 分页信息（如果适用）
}
```

## 个人中心接口

### 1. 刷新Token

**接口地址**: `POST /common/token/refreshToken`

**接口描述**: 刷新访问令牌

**请求参数**:

| 参数名          | 类型     | 必填 | 说明          | 示例           |
|--------------|--------|----|-------------|--------------|
| refreshToken | String | 是  | 刷新令牌,登录时返回的 | refreshToken |

**请求示例**:

```json
{
  "refreshToken": "example_refresh_token"
}
```

**响应业务数据**:

```json
{
  "jwtToken": "new_jwt_token",
  "refreshToken": "new_refresh_token"
}
```

### 2. 获取登录用户信息

**接口地址**: `GET /common/token/findUserInfo`

**接口描述**: 获取当前登录用户的信息，包括基本信息、角色、权限和企业信息

**请求参数**: 无

**响应业务数据**:

```json
{
  "baseInfo": {
    // 用户基本信息，根据角色不同可能是 AuAdmin、AuUser 或 AuStoreAdmin 对象
  },
  "role": "Admin",
  // 用户角色：Admin/User/Store/Root
  "permission": "permission_string",
  // 权限信息（管理员角色才有）
  "auEnterprise": {
    // 企业信息（管理员和门店管理员角色才有）
  }
}
```

**响应字段说明**:

- `baseInfo`: 用户基本信息对象，具体结构根据用户角色不同而不同
- `role`: 用户角色类型
- `permission`: 权限字符串，仅管理员角色返回
- `auEnterprise`: 企业信息对象，管理员和门店管理员角色返回

#### baseInfo 对象详细字段说明

所有用户对象都继承自 BaseEntity，包含以下公共字段：

| 字段名        | 类型      | 说明                         |
|------------|---------|----------------------------|
| id         | String  | 用户ID                       |
| enId       | String  | 所属企业ID                     |
| createTime | String  | 创建时间 (yyyy-MM-dd HH:mm:ss) |
| updateTime | String  | 更新时间 (yyyy-MM-dd HH:mm:ss) |
| note       | String  | 备注                         |
| version    | Integer | 数据版本                       |

##### 1. 管理员(Admin) - AuAdmin 对象

##### 3. 门店管理员(Store) - AuStoreAdmin 对象

## 5.保存我的收货地址

**接口地址**: `POST /app/user/address/saveAddress`

**接口描述**: 保存我的收货地址（新增或更新）

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | String | 否 | 地址ID，没有则新增 | "1234567890" |
| note | String | 否 | 备注 | "" |
| version | Integer | 否 | 数据版本 | 0 |
| name | String | 是 | 收货人姓名 | "张三" |
| phone | String | 是 | 手机号 | "13800138000" |
| country | String | 是 | 国家 | "中国" |
| province | String | 是 | 省 | "北京市" |
| city | String | 是 | 城市 | "北京市" |
| town | String | 是 | 城镇(地级市) | "朝阳区" |
| address | String | 是 | 详细地址 | "某某大厦1层101室" |
| def | Integer | 是 | 是否默认地址{0:不默认,1:默认} | 1 |

**注意**: userId和enId会自动从当前登录用户信息中获取，前端不需要传递。

{
