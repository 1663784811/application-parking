# 验证码接口文档

## 通用响应格式
所有接口返回的通用响应格式如下：
```json
{
  "code": 2000,           // 状态码
  "msg": "操作成功",      // 提示信息
  "data": {},           // 返回数据
  "result": null        // 分页信息（如果适用）
}
```

## 验证码接口
### 1. 获取图片验证码
**接口地址**: `POST /common/verify/getVerifyCode`
**接口描述**: 获取图片验证码
**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| fingerprint | String | 是 | 验证码指纹 | fingerprint |

**请求示例**:
```json
{
  "fingerprint": "example_fingerprint"
}
```

**响应示例**:
```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": "verification_code_123456"
}
```

### 2. 获取验证码图片
**接口地址**: `GET /common/verify/getVerifyImg/{keyCode}`

**接口描述**: 获取验证码图片

**路径参数**:

| 参数名 | 类型 | 必填 | 说明                   |
|--------|------|------|----------------------|
| keyCode | String | 是 | 验证码键值：通过 1.获取图片验证码获取 |

**响应**: 返回验证码图片的PNG格式数据

### 3. 获取手机验证码

**接口地址**: `POST /common/verify/getVerifyPhoneCode`

**接口描述**: 获取手机验证码

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| fingerprint | String | 是 | 验证码指纹 | fingerprint |
| phone | String | 是 | 手机号 | phone |

**请求示例**:
```json
{
  "fingerprint": "example_fingerprint",
  "phone": "13800138000"
}
```

**响应示例**:
```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": "phone_verification_code_123456"
}
```
