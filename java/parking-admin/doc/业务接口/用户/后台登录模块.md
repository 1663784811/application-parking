# 后台登录模块接口文档

> Controller：`com.cyyaw.admin.application.user.controller.login.AdminLoginController`
> 路径前缀：`/admin/login`
> 权限：`/admin/login/**` 已在 `SecurityConfig` 白名单内 `permitAll`，**全部免登录**
> 响应封装：`BaseResult<T>`，字段见下方「通用响应结构」

---

## 通用响应结构 BaseResult

```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": { },
  "result": null
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 状态码，`2000` 表示成功，其余见文末错误码表 |
| `msg` | string | 提示信息 |
| `data` | object/array/null | 业务数据，结构随接口而定 |
| `result` | object/null | 分页信息 `{ total, page, size }`，非分页接口为 `null` |

## 一、企业管理员登录

### 基本信息

| 项 | 值 |
| --- | --- |
| 路径 | `POST /admin/login/login` |
| 鉴权 | 免登录 |
| Content-Type | `application/json` |
| 请求体 | `LoginRequest` |
| 响应 `data` | `LoginRest` |

### 请求参数

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `enId` | Long | 是 | — | 企业 ID |
| `username` | String | 是 | 3~18 位（`Reg.UserName_REGEX`） | 用户名 |
| `password` | String | 是 | 6 位数字/字母/特殊字符（`Reg.PASSWORD_REGEX`） | 密码 |
| `code` | String | 是 | — | 图片验证码 |
| `fingerprint` | String | 是 | 设备指纹（`Reg.Fingerprint_REGEX`） | 验证码指纹，用于校验验证码归属 |

> `fingerprint` 继承自父类 `VerifyRequest`。

### 请求示例

```json
{
  "enId": 1,
  "username": "admin",
  "password": "123456",
  "code": "a1b2",
  "fingerprint": "8f14e45fceea167a5a36dedd4bea2543"
}
```

### 响应字段（LoginRest）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `jwtToken` | String | JWT 访问令牌 |
| `refreshToken` | String | JWT 刷新令牌（长效） |

### 响应示例

```json
{
  "code": 2000,
  "msg": "登录成功",
  "data": {
    "jwtToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9..."
  },
  "result": null
}
```

### 业务流程与错误码

1. 校验 `username` / `code` 非空
2. 按 `enId` 查询企业，不存在则失败
3. 校验图片验证码（Redis key `VERIFY_CODE:{fingerprint}`），校验后删除
4. 按账号 + 企业查 `au_admin`，不存在则失败
5. `BCrypt` 校验密码
6. 生成 `jwtToken` + `refreshToken` 返回

| 场景 | 枚举 | code | msg |
| --- | --- | --- | --- |
| 用户名/验证码为空 | `WEB_ILLEGALSTATE` | 5000 | 参数错误 |
| 企业不存在 | `WEB_AUTHENTICATION_ERR` | 6020 | 没有权限 |
| 验证码错误 | `WEB_LOGINERR` | 6000 | 验证码错误 |
| 用户不存在 / 密码错误 | `WEB_LOGINERR` | 6000 | 用户名或密码错误 |

## 二、企业管理员注册

### 基本信息

| 项 | 值 |
| --- | --- |
| 路径 | `POST /admin/login/register` |
| 鉴权 | 免登录 |
| Content-Type | `application/json` |
| 请求体 | `AdminRegisterRequest` |
| 响应 `data` | `AuAdmin`（企业管理员） |

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `enId` | Long | 是 | 企业 ID |
| `username` | String | 是 | 账号 |
| `password` | String | 是 | 密码（建议前端加密传输） |
| `phone` | String | 是 | 手机号 |
| `code` | String | 是 | 手机验证码 |
| `fingerprint` | String | 是 | 验证码指纹（继承自 `VerifyRequest`） |

### 请求示例

```json
{
  "enId": 1,
  "username": "shopadmin",
  "password": "123456",
  "phone": "13800000000",
  "code": "123456",
  "fingerprint": "8f14e45fceea167a5a36dedd4bea2543"
}
```

### 响应字段（AuAdmin）

继承 `BaseEntity`（`id` / `enId` / `createTime` / `updateTime` / `note` / `delTime`）+ 自身字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long(string) | 主键，JSON 输出为字符串 |
| `enId` | Long(string) | 所属企业 ID |
| `account` | String | 账号 |
| `phone` | String | 手机号 |
| `nickName` | String | 昵称 |
| `avatar` | String | 头像 |
| `realName` | String | 真实姓名 |
| `gender` | Integer | 性别 `{0:未知, 1:男, 2:女}` |
| `birthday` | String | 生日（`yyyy-MM-dd`） |
| `email` | String | 邮箱 |
| `createTime` | String | 创建时间（`yyyy-MM-dd HH:mm:ss`） |
| `updateTime` | String | 更新时间（`yyyy-MM-dd HH:mm:ss`） |
| `note` | String | 备注 |
| `delTime` | Integer | 软删除标记（`0`=未删） |

> `password` 字段标注 `@JsonIgnore`，**响应中不返回**。

### 响应示例

```json
{
  "code": 2000,
  "msg": "注册成功",
  "data": {
    "id": "101",
    "enId": "1",
    "account": "shopadmin",
    "phone": "13800000000",
    "nickName": "shopadmin",
    "avatar": null,
    "realName": null,
    "gender": 0,
    "birthday": null,
    "email": null,
    "createTime": "2026-08-21 10:00:00",
    "updateTime": "2026-08-21 10:00:00",
    "note": "",
    "delTime": 0
  },
  "result": null
}
```

### 业务流程与错误码

1. 校验手机验证码（Redis key `phoneVerifyCodeKey(phone, fingerprint)`）
2. 按 `enId` 查询企业，不存在则失败
3. 按账号 + 企业查 `au_admin`，已存在则失败
4. `BCrypt` 加密密码后入库
5. 返回新建管理员

| 场景 | 枚举 | code | msg |
| --- | --- | --- | --- |
| 验证码为空 | — | — | 验证码不能为空 |
| 验证码错误 | `WEB_LOGINERR` | 6000 | 验证码错误 |
| 企业不存在 | `WEB_REGISTER_ERR` | 6002 | 企业不存在 |
| 账号已注册 | `WEB_REGISTER_ERR` | 6002 | 账号已被注册 |

## 三、查询是否存在企业

### 基本信息

| 项 | 值 |
| --- | --- |
| 路径 | `GET /admin/login/findAny` |
| 鉴权 | 免登录 |
| 请求参数 | 无 |
| 响应 `data` | `AuEnterprise` 或 `null` |

### 说明

查询企业表 `au_enterprise`，只取一条（`LIMIT 1`），用于登录页判断系统是否已初始化、是否需要引导注册企业。SQL 已过滤软删除（`del_time = 0`）。

### 请求示例

```
GET /admin/login/findAny
```

### 响应字段（AuEnterprise）

继承 `BaseEntity` + 自身字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long(string) | 主键 |
| `enId` | Long(string) | 所属企业 ID（企业自身为 `0`） |
| `name` | String | 企业名称 |
| `logo` | String | logo |
| `code` | String | 企业编码（唯一） |
| `person` | String | 联系人 |
| `rootAccount` | String | 企业管理员账号 |
| `phone` | String | 联系电话（唯一） |
| `address` | String | 地址 |
| `status` | Integer | 状态 `{0:禁用, 1:启用}` |
| `createTime` | String | 创建时间 |
| `updateTime` | String | 更新时间 |
| `note` | String | 备注 |
| `delTime` | Integer | 软删除标记 |

### 响应示例

**有企业：**

```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": {
    "id": "1",
    "enId": "0",
    "name": "示例企业",
    "logo": null,
    "code": "E20260821001",
    "person": "张三",
    "rootAccount": "13800000000",
    "phone": "13800000000",
    "address": "某地",
    "status": 1,
    "createTime": "2026-08-21 10:00:00",
    "updateTime": "2026-08-21 10:00:00",
    "note": "",
    "delTime": 0
  },
  "result": null
}
```

**无企业：**

```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": null,
  "result": null
}
```
