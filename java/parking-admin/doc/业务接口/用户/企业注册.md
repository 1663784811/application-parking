# 企业注册接口


## 通用响应格式
所有接口返回的通用响应格式如下：
```json
{
  "code": 2000,           // 状态码
  "msg": "操作成功",      // 提示信息
  "data": {},           // 返回业务数据, 数组、对象、字符串等等
  "result": null        // 分页信息（如果适用）
}
```

## 1.注册企业
**接口地址**: `POST /root/login/registerEnterprise`

**接口描述**: 注册企业

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| name | String | 是 | 企业名称，3位以上长度 | "科技有限公司" |
| logo | String | 是 | 企业Logo | "https://example.com/logo.png" |
| person | String | 是 | 联系人，2位以上长度 | "张三" |
| phone | String | 是 | 联系人手机号，11位手机号 | "13800138000" |
| username | String | 是 | 管理员账号，3至18位字母数字下划线 | "admin123" |
| password | String | 是 | 密码，6-16位数字或字母 | "password123" |
| code | String | 是 | 验证码 | "123456" |
| fingerprint | String | 是 | 验证码指纹，3-64位字母数字下划线 | "device_fingerprint_123" |

**请求示例**:
```json
{
  "name": "科技有限公司",
  "logo": "https://example.com/logo.png",
  "person": "张三",
  "phone": "13800138000",
  "username": "admin123",
  "password": "password123",
  "code": "123456",
  "fingerprint": "device_fingerprint_123"
}
```

**响应参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| id | Long | 是 | 企业ID | 1001 |
| name | String | 是 | 企业名称 | "科技有限公司" |
| logo | String | 是 | 企业Logo | "https://example.com/logo.png" |
| eCode | String | 是 | 企业编号 | "ENT001" |
| person | String | 是 | 联系人 | "张三" |
| phone | String | 是 | 手机号 | "13800138000" |
| username | String | 是 | 管理员账号 | "admin123" |

**响应业务数据**:
```json
{
  "id": 1001,
  "name": "科技有限公司",
  "logo": "https://example.com/logo.png",
  "eCode": "ENT001",
  "person": "张三",
  "phone": "13800138000",
  "username": "admin123"
}
```

## 2.超级管理员登录
**接口地址**: `POST /root/login/login`

**接口描述**: 超级管理员登录

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| username | String | 是 | 用户名 | "admin" |
| password | String | 是 | 密码 | "password123" |

**请求示例**:
```json
{
  "username": "admin",
  "password": "password123"
}
```

**响应参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | Integer | 是 | 状态码 |
| msg | String | 是 | 提示信息 |
| data | Object | 否 | 返回业务数据 |

**响应业务数据**:
```json
null
```

## 3.获取超级管理员登录信息
**接口地址**: `POST /root/login/findRootInfo`

**接口描述**: 获取超级管理员登录信息

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| eCode | String | 是 | 企业编号 | "ENT001" |

**请求示例**:
```json
{
  "eCode": "ENT001"
}
```

**响应参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | Integer | 是 | 状态码 |
| msg | String | 是 | 提示信息 |
| data | Object | 否 | 返回业务数据 |

**响应业务数据**:
```json
{
  "id": 1001,
  "username": "admin",
  "name": "超级管理员"
}
```
