# 停车场后台管理系统设计规范（单机版）

> 适用部署：`single-all` 单体部署（单 JVM，无网关、无注册中心）
> 根仓库：`java/parking-admin`
> 根 parent：`com.cyyaw.admin:admin-parent:1.0.1`（继承 `spring-boot-starter-parent:4.0.2`，Java 21）

本规范基于项目现有代码提炼，描述**单机部署模式**下的模块划分、启动配置、安全设计、数据层与「增删查改」分层约定。新增功能请严格遵循，以保证结构统一。微服务部署另见《系统设计规范（微服务版）》。

## 二、模块定义

### 2.1 Reactor 模块（admin-parent 下）

| 模块 | artifactId | 职责 |
| --- | --- | --- |
| 实体层 | `admin-entity` | 数据库映射实体、DTO、枚举、Redis 配置、公共基类 |
| 数据访问层 | `admin-dao` | Mapper 接口、`BaseMapperPlus`、`BaseService` 通用查询 |
| 通用层 | `admin-common` | `BaseResult` 响应封装、错误码、异常、工具类 |
| 配置层 | `admin-config` | `JwtTokenUtil` 等 |
| 业务层 | `application-user` | Controller + Service（用户 / 登录 / 菜单 / 企业 / 门店 等） |
| 单机启动器 | `single-all` | Spring Security 壳 + 启动类，聚合上述全部模块 |

**依赖链**：`single-all` → `application-user` → { `admin-entity`、`admin-dao`、`admin-common`、`admin-config` }；`admin-dao` → `admin-entity` → `admin-common`。`single-all` 不直接声明 `admin-*` 依赖，全部经 `application-user` 传递引入。

> ⚠️ `admin-dao` 当前**未列入** `admin-parent` 的 `<modules>`，全量构建前需确保其已 `install` 至本地仓库。

### 2.2 各模块职责与包结构

groupId = `com.cyyaw.admin`

**admin-entity**（`com.cyyaw.admin.entity`）
- `entity.module.<模块>` —— 数据库映射实体，如 `entity.module.user`
- `entity.dto.<模块>` —— 请求 / 响应 DTO，如 `entity.dto.user.login`
- `entity.em` —— 枚举（`SystemRoleEnum`、`AppEnum`、`IotDeviceTypeEnum` 等）
- `entity.redis` —— Redis 配置与工具（`RedisConfig`、`RedisKey`、`RedisUtils`）
- `entity.utils` —— 公共基类与工具（`BaseEntity`、`LoginInfo`、`LoginInfoContext`、`TreeResponseEntity`）

**admin-dao**（`com.cyyaw.admin.dao`）
- `dao.<模块>` —— Mapper 接口，如 `dao.user`
- `dao.service` —— 通用查询基类（`BaseTableService`、`BaseService`、`WhereType`）
- `dao` —— `BaseMapperPlus`

**admin-common**（`com.cyyaw.admin.common`）
- `BaseResult`、`WebErrCodeEnum`、`WebException`、`SnowflakeIdGenerator`、`SqlUtils`、`RegexUtils`、`ReadExcelUtils` 等

**admin-config**（`com.cyyaw.admin.config`）
- `config.utils` —— `JwtTokenUtil`、`RefreshTokenInfo`

**application-user**（`com.cyyaw.admin.application.user`）
- `controller/<端>` —— 按端划分：`admin`、`login`、`user`
- `service` —— Service 接口
- `service.impl` —— Service 实现

**single-all**（`com.cyyaw.sigle`）
- 启动类 `SigleAllApplication`
- `SecurityConfig`、`JwtAuthenticationFilter`、`CustomUserDetailsService`
- 无业务代码（薄启动器 + 安全壳），全部业务由 `application-user` 提供

## 三、启动与配置

### 3.1 启动类

`com.cyyaw.sigle.SigleAllApplication`

```java
@Slf4j
@SpringBootApplication(scanBasePackages = {"com.cyyaw.sigle", "com.cyyaw.admin.application.user"})
@MapperScan(basePackages = {"com.cyyaw.admin.dao.**"})
public class SigleAllApplication {
    public static void main(String[] args) {
        SpringApplication.run(SigleAllApplication.class, args);
    }
}
```

- `scanBasePackages`：扫描安全壳 `com.cyyaw.sigle` + 业务层 `com.cyyaw.admin.application.user`
- `@MapperScan`：扫描 `admin-dao` 下全部 Mapper（`com.cyyaw.admin.dao.**`）
- 不含 `@EnableDiscoveryClient` / `@EnableFeignClients`（单机无需）

### 3.2 端口与 profile

- 端口 **10000**（`application.yml`）
- `spring.profiles.active = log,mysql,mybatis`

### 3.3 配置文件

| 文件 | 作用 |
| --- | --- |
| `application.yml` | 端口 10000、profile、application name |
| `application-mysql.yml` | 数据源 `localhost:3306/t_parking`、`mybatis-plus.mapper-locations` |
| `application-mybatis.yml` | `id-type:ASSIGN_ID`（雪花）、`logic-delete-value:1` / `0`、`map-underscore-to-camel-case`、`type-aliases-package:com.cyyaw.admin.entity.module`、`log-impl:StdOutImpl` |
| `application-log.yml` | 日志级别 |
| `logback-spring.xml` | 日志目录 `./logs/admin-user`，100MB 滚动、保留 30 天 |

## 四、安全设计（单机）

单机版用 Spring Security + JWT 在进程内统一鉴权，无网关。

### 4.1 SecurityConfig（`com.cyyaw.sigle.SecurityConfig`）

- `@EnableWebSecurity`，CSRF 关闭，会话策略 `STATELESS`
- 白名单 `permitAll`：`/swagger-ui/**`、`/v3/api-docs/**`、`/doc.html`、`/webjars/**`、`/admin/login/**`、`/app/login/**`、`/store/login/**`、`/common/**`、`/root/login/registerEnterprise`、`/common/verify/getVerifyCode` 等；其余 `anyRequest().authenticated()`
- 在 `UsernamePasswordAuthenticationFilter` 之前注册 `JwtAuthenticationFilter`
- CORS：`allowedOriginPatterns("*")`，允许凭证
- Bean：`BCryptPasswordEncoder`、`AuthenticationManager`、自定义 `AccessDeniedHandler`（403）、`AuthenticationEntryPoint`（401，`WebErrCodeEnum.WEB_NOT_LOGIN`）

### 4.2 JwtAuthenticationFilter（`com.cyyaw.sigle.JwtAuthenticationFilter`）

- `extends OncePerRequestFilter`
- 读取 `Authorization: Bearer <jwt>`
- 调用 `JwtTokenUtil.verifierToken` 校验
- 解析 token 的 `data` claim → `LoginInfo` → 存入 `LoginInfoContext`（ThreadLocal，`finally` 中清除）
- `ExpiredJwtException` 仅告警日志，不阻断链路

### 4.3 登录上下文 LoginInfo / LoginInfoContext

`LoginInfo` 字段：`enId`（企业）、`appId`、`storeId`、`id`、`account`、`nickName`、`systemRole`、`role`、`permission`。
业务层统一通过 `LoginInfoContext.getLoginInfo()` 获取当前登录上下文；`BaseEntity` 的 `@PrePersist` 亦据此回填 `enId`。

> ⚠️ `JwtTokenUtil` 当前 secret 与过期时间为**硬编码**，未读取 yml `jwt.*`；`CustomUserDetailsService` 为桩实现（真实身份来自 JWT 本身）。改进建议见第十节。

## 五、数据层规范

### 5.1 BaseEntity（`entity.utils.BaseEntity`）

`@MappedSuperclass`，所有实体继承。公共字段：

| 字段 | 列名 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | `id` | `Long` | 主键，`@GeneratedValue(IDENTITY)`，`@JsonFormat(STRING)` 输出为字符串（避免前端 JS 精度丢失） |
| `enId` | `en_id` | `Long` | 企业 ID，`@TableField(fill=INSERT)` 自动填充 |
| `createTime` | `create_time` | `LocalDateTime` | `@PrePersist` 自动填充 |
| `updateTime` | `update_time` | `LocalDateTime` | `@PrePersist` / `@PreUpdate` 自动填充 |
| `note` | `note` | `String` | 备注 |
| `delTime` | `del_time` | `Integer` | 软删除标记（0 = 未删） |

`@PrePersist` 中从 `LoginInfoContext` 取 `enId` 自动回填。

### 5.2 实体类规范

- 包：`entity.module.<模块>`
- 注解：`@Data @Entity @Table(name="") @EqualsAndHashCode(callSuper=true) extends BaseEntity`
- 字段：`@Column(name="", columnDefinition="... COMMENT '...'")` + `@Schema(description="")`
- 同时使用 JPA（DDL / 列映射）与 MyBatis-Plus（`@TableField` 填充）

### 5.3 DTO 规范

- 包：`entity.dto.<模块>`
- 命名后缀：请求 `XxxRequest`、响应 `XxxRest`

### 5.4 Mapper（`admin-dao`）

- `interface XxxDao extends BaseMapperPlus<XxxDao, Xxx>`
- `BaseMapperPlus<M, T extends BaseEntity> extends BaseMapper<T>`，扩展：`save(T)`（按 id upsert）、`insertBatch`、`updateBatchById`、`insertOrUpdateBatch`、`selectVoPage` 等
- 自定义查询用 `@Select` 注解，默认不写 XML（`mapper-locations` 保留 `classpath:mapper/**/*.xml` 兜底）

### 5.5 通用查询基类

- `BaseTableService<T>`：`findByExample(T)`、`findPage(JSONObject json, Class<T> clazz)`
- `BaseService<M extends BaseMapperPlus, T> implements BaseTableService<T>`：基于 `QueryWrapper` 反射 `@Column` 构建动态条件与排序，分页返回 `BaseResult<List<T>>`

## 六、增删查改规范

### 6.1 分层调用流

```
Controller → Service(接口) → ServiceImpl → Dao(BaseMapperPlus) → DB
```

- `ServiceImpl` 继承 `BaseService<Dao, Entity>` 即获得 `findByExample` / `findPage`
- 写操作优先用 `BaseMapperPlus.save(entity)`（id 存在则 update，否则 insert）

### 6.2 Controller 规范

- 包：`controller/<端>`（`admin` / `login` / `user`）
- 注解：`@Tag(name="")`、`@RestController`、`@RequestMapping("/<端>/<模块>")`
- 方法：`@Operation(summary="", description="")` + `@GetMapping` / `@PostMapping`，返回 `BaseResult<T>`，入参 `@RequestBody`
- 路径前缀：`/admin/*`、`/app/*`、`/store/*`、`/root/*`、`/common/*`
- 当前用户：`LoginInfoContext.getLoginInfo()`

### 6.3 Service 规范

- 接口在 `service/`，实现 `service/impl/` 标注 `@Service`
- 需通用分页 / 示例查询的接口 `extends BaseTableService<T>`；实现 `extends BaseService<XxxDao, Xxx>`
- 注入 Dao：`@Autowired private XxxDao xxxDao`

### 6.4 响应封装 BaseResult

```json
{
  "code": 2000,
  "msg": "操作成功",
  "data": { },
  "result": { "total": 0, "page": 1, "size": 30 }
}
```

- 静态工厂：`ok()`、`ok(data)`、`ok(data, result)`、`fail(msg)`、`rest(WebErrCodeEnum)`
- `result` 仅分页接口返回（`total` / `page` / `size`）

### 6.5 分页与动态查询（findPage）

请求体（`JSONObject`）约定键：

- `page`：页码（默认 1）；`size`：每页条数（默认 30）；`sort`：排序，形如 `createTime_desc,account_asc`
- 条件键以 **`WhereType` 前缀 + 属性名** 组成：

| 前缀 | 含义 | 前缀 | 含义 |
| --- | --- | --- | --- |
| `eq_` | `=` | `neq_` | `!=` |
| `lk_` | `LIKE %x%` | `lkR_` / `lkL_` | `x%` / `%x` |
| `geq_` | `>=` | `gt_` | `>` |
| `leq_` | `<=` | `lt_` | `<` |
| `in_` | `IN`（逗号分隔） | | |

示例：

```json
{ "page": 1, "size": 10, "lk_account": "admin", "eq_state": 1, "sort": "createTime_desc" }
```

### 6.6 软删除

`delTime` 字段标记删除；MyBatis-Plus 逻辑删除配置 `logic-delete-value=1` / `logic-not-delete-value=0`。禁止物理删除业务数据。

## 十、已知问题与改进建议

1. `admin-dao` 未纳入 `admin-parent` reactor `<modules>` —— 补入以支持一键构建。
2. `application.yml` 的 `spring.application.name` 残留 `cloud-application-user` —— 改为 `single-all` 或 `parking-admin`。
3. `JwtTokenUtil` 硬编码 secret 与过期时间，未读取 yml `jwt.*` —— 改为配置化（`@Value` / `@ConfigurationProperties`）。
4. Redis 已引入但 `VerifyCodeServiceImpl` 中 Redis 调用全部注释 —— 启用验证码缓存或移除依赖。
5. `CustomUserDetailsService` 为桩实现 —— 按需实现或移除（鉴权依赖 JWT）。
6. `application-log.yml` / `logback-spring.xml` 残留 feign / nacos / hibernate logger —— 清理单机无效配置。
7. 启动类日志端口缺失 —— 补全提示信息。
