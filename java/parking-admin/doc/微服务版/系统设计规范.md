# 停车场后台管理系统设计规范（微服务版）

> 适用部署：`cloud-*` 微服务部署（网关 + 注册中心 + 配置中心）
> 根仓库：`java/parking-admin`
> 根 parent：`com.cyyaw.admin:admin-parent:1.0.1`（继承 `spring-boot-starter-parent:4.0.2`，Java 21）
> 微服务 parent：`com.cyyaw.admin:cloud-parent:1.0.1`

本规范基于项目现有代码提炼，描述**微服务部署模式**下的模块划分、网关、Nacos、Feign、安全、数据层与「增删查改」分层约定。新增功能请严格遵循，以保证结构统一。单机部署另见《系统设计规范（单机版）》。

## 三、网关（cloud-application-gateway）

### 3.1 启动类

`com.cyyaw.cloud.application.gateway.CloudGatewayApplication`

```java
@Slf4j
@EnableDiscoveryClient
@SpringBootApplication
@LoadBalancerClients({@LoadBalancerClient("spring-gateway")})
@EnableFeignClients
public class CloudGatewayApplication { }   // http://127.0.0.1:9000
```

### 3.2 配置（application.yml）

- 端口 **9000**，`spring.application.name=cloud-application-gateway`，`profiles.active=log`
- Nacos：`192.168.221.38:8848`（nacos/nacos），同时用于发现与配置
- 配置中心：`spring.config.import=nacos:nacos-config-example.properties?refreshEnabled=true`
- 负载均衡：`ribbon.enabled=false`，`spring.cloud.loadbalancer.nacos.enabled=true`
- actuator：`management.endpoints.web.exposure.include='*'`
- knife4j 聚合：`strategy:DISCOVER`，`version:OpenAPI3`，自动从 Nacos 发现下游并聚合文档

### 3.3 路由

静态路由（yml 声明，无 `RouteLocator` Java Bean、无动态路由）：

```yaml
spring:
  cloud:
    gateway:
      server:
        webflux:
          routes:
            - id: admin-user
              uri: lb://admin-user
              predicates:
                - Path=/user/**
```

> ⚠️ 当前路由 `lb://admin-user` 与用户服务注册名 `cloud-application-user` **不一致**，需对齐服务名。

### 3.4 鉴权 AuthFilter

`@Component implements GlobalFilter, Ordered`（`order = -100`）：

- 读取 `Authorization: Bearer <token>`，回退 `?token=`
- 白名单（放行）：`/auth/**`、`/login`、`/register`、`/health`、`/actuator/**`、`/doc.html`、`/webjars/**`、`/swagger-resources/**`、`/v3/api-docs/**`、`/favicon.ico`
- 调用 `AuthClient.validateToken(authorization)`；无效返回 **401**，异常返回 **500**
- `AuthClient` 为 Feign 客户端：`@FeignClient(name="admin-auth", path="/auth")`，`GET /validate`

> ⚠️ `admin-auth` 服务在当前仓库内**不存在**，`/auth/validate` 无实现 —— 网关鉴权依赖外部 / 待建设的 `admin-auth` 服务。

### 3.5 限流 / 熔断（规划态）

- `RateLimitFilter`（`order = -50`）：当前为日志桩（放行所有请求）
- `RateLimitConfig`、`SentinelConfig`：当前**全部注释**
- 资源：`application-sentinel.yml`、`sentinel-rules.json`（admin-user 10 QPS、admin-auth 5 QPS）

> 现状未真正生效；规划用 Sentinel + `RequestRateLimiter`（需 Redis）。

### 3.6 静态资源

`static/index.html`：访问 `/` 跳转 `/doc.html`。

## 四、用户服务（cloud-application-user）

### 4.1 启动类

`com.cyyaw.cloud.application.user.CloudUserApplication`

```java
@SpringBootApplication
@EnableDiscoveryClient
@EnableFeignClients
public class CloudUserApplication { }   // port 9001
```

- 端口 **9001**，`spring.application.name=cloud-application-user`
- profiles：`log,mysql,mybatis`
- 依赖 `application-user` 提供全部 Controller / Service

> ⚠️ 缺少 `@MapperScan`（`admin-dao` 的 Mapper 无 `@Mapper` 注解）—— 建议补 `@MapperScan("com.cyyaw.admin.dao.**")`。

### 4.2 配置

- `application-mysql.yml`：数据源 `localhost:3306/t_parking`
- `application-mybatis.yml`：`id-type:ASSIGN_ID`（雪花）、`logic-delete-value:1/0`、`map-underscore-to-camel-case`、`type-aliases-package:com.cyyaw.admin.entity.module`、`mapper-locations:classpath:mapper/**/*.xml`、`cache-enabled:false`
- Nacos 地址同网关

### 4.3 服务间调用

OpenFeign：网关 `AuthClient` 调 `admin-auth`。新增跨服务调用时定义 `@FeignClient(name=服务名)`，服务名须与目标服务在 Nacos 的注册名一致。

## 五、Nacos（注册 + 配置中心）

- docker：`nacos/nacos-server:v3.1.1`，standalone，端口 `8848` / `8080`，MySQL 库 `t_nacos`，账号 `nacos/nacos`
- 服务向 Nacos 注册（`@EnableDiscoveryClient`），网关按服务名路由（`lb://服务名`）
- 配置中心：`spring.config.import=nacos:<dataId>?refreshEnabled=true`，支持动态刷新

## 六、安全设计（微服务）

| 关注点 | 约定 |
| --- | --- |
| 鉴权位置 | 集中在网关 `AuthFilter`（反应式 `GlobalFilter`），委托 `admin-auth` 校验 JWT |
| 下游服务 | 默认不再鉴权，信任网关内网调用 |
| CORS | 网关需配置 `CorsWebFilter`（当前缺失，见第十节） |
| 与单机差异 | 单机用进程内 Spring Security + `JwtAuthenticationFilter`；微服务用网关统一鉴权 + Feign 校验 |

## 七、数据层规范

### 7.1 BaseEntity（`entity.utils.BaseEntity`）

`@MappedSuperclass`，所有实体继承。公共字段：

| 字段 | 列名 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | `id` | `Long` | 主键，`@GeneratedValue(IDENTITY)`，`@JsonFormat(STRING)` 输出字符串（避免前端精度丢失） |
| `enId` | `en_id` | `Long` | 企业 ID，`@TableField(fill=INSERT)` 自动填充 |
| `createTime` | `create_time` | `LocalDateTime` | `@PrePersist` 自动填充 |
| `updateTime` | `update_time` | `LocalDateTime` | `@PrePersist` / `@PreUpdate` 自动填充 |
| `note` | `note` | `String` | 备注 |
| `delTime` | `del_time` | `Integer` | 软删除标记（0 = 未删） |

### 7.2 实体类规范

- 包：`entity.module.<模块>`
- 注解：`@Data @Entity @Table(name="") @EqualsAndHashCode(callSuper=true) extends BaseEntity`
- 字段：`@Column(name="", columnDefinition="... COMMENT '...'")` + `@Schema(description="")`

### 7.3 DTO 规范

- 包：`entity.dto.<模块>`；后缀 `XxxRequest` / `XxxRest`

### 7.4 Mapper（`admin-dao`）

- `interface XxxDao extends BaseMapperPlus<XxxDao, Xxx>`
- `BaseMapperPlus<M, T extends BaseEntity> extends BaseMapper<T>`：`save(T)` upsert、`insertBatch`、`selectVoPage` 等
- 自定义查询用 `@Select` 注解

### 7.5 通用查询基类

- `BaseTableService<T>`：`findByExample(T)`、`findPage(JSONObject, Class<T>)`
- `BaseService<M extends BaseMapperPlus, T> implements BaseTableService<T>`：反射 `@Column` 构建动态 `QueryWrapper`，分页返回 `BaseResult<List<T>>`

## 八、增删查改规范

### 8.1 分层调用流

```
Controller → Service(接口) → ServiceImpl → Dao(BaseMapperPlus) → DB
```

- `ServiceImpl` 继承 `BaseService<Dao, Entity>` 获得 `findByExample` / `findPage`
- 写操作优先 `BaseMapperPlus.save(entity)`（id 存在则 update，否则 insert）

### 8.2 Controller 规范

- 包：`controller/<端>`（`admin` / `login` / `user`）
- 注解：`@Tag(name="")` `@RestController` `@RequestMapping("/<端>/<模块>")`
- 方法：`@Operation(summary="", description="")` + `@GetMapping` / `@PostMapping`，返回 `BaseResult<T>`，入参 `@RequestBody`
- 路径前缀：`/admin/*`、`/app/*`、`/store/*`、`/root/*`、`/common/*`
- 当前用户：`LoginInfoContext.getLoginInfo()`

### 8.3 Service 规范

- 接口 `service/`，实现 `service/impl/` 标注 `@Service`
- 需分页的接口 `extends BaseTableService<T>`；实现 `extends BaseService<XxxDao, Xxx>`
- 注入 Dao：`@Autowired private XxxDao xxxDao`

### 8.4 响应封装 BaseResult

```json
{ "code": 2000, "msg": "操作成功", "data": { }, "result": { "total": 0, "page": 1, "size": 30 } }
```

- 静态工厂：`ok()`、`ok(data)`、`ok(data, result)`、`fail(msg)`、`rest(WebErrCodeEnum)`
- `result` 仅分页接口返回

### 8.5 分页与动态查询（findPage）

请求体（`JSONObject`）约定键：`page`（默认 1）、`size`（默认 30）、`sort`（如 `createTime_desc,account_asc`）。条件键以 `WhereType 前缀 + 属性名` 组成：

| 前缀 | 含义 | 前缀 | 含义 |
| --- | --- | --- | --- |
| `eq_` | `=` | `neq_` | `!=` |
| `lk_` | `LIKE %x%` | `lkR_` / `lkL_` | `x%` / `%x` |
| `geq_` | `>=` | `gt_` | `>` |
| `leq_` | `<=` | `lt_` | `<` |
| `in_` | `IN`（逗号分隔） | | |

示例：`{ "page":1, "size":10, "lk_account":"admin", "eq_state":1, "sort":"createTime_desc" }`

### 8.6 软删除

`delTime` 标记；MyBatis-Plus 逻辑删除 `logic-delete-value=1` / `logic-not-delete-value=0`，禁止物理删除。

## 十、已知问题与改进建议

1. `cloud-application-user` 未纳入 `cloud-parent` reactor `<modules>` —— 补入。
2. 网关路由 `lb://admin-user` 与用户服务注册名 `cloud-application-user` 不一致 —— 对齐服务名。
3. `admin-auth` 服务缺失（`AuthClient` 无后端）—— 建设鉴权服务或改用网关本地校验 JWT。
4. `RateLimitConfig` / `SentinelConfig` 全部注释、`RateLimitFilter` 为日志桩 —— 补全 Sentinel + Redis 限流或移除死代码。
5. 网关无 CORS 配置 —— 浏览器直连需补 `CorsWebFilter`。
6. `CloudUserApplication` 缺 `@MapperScan` —— 补 `@MapperScan("com.cyyaw.admin.dao.**")`。
7. `JwtTokenUtil` 硬编码 secret 与过期时间 —— 配置化。

## 十一、单机 vs 微服务 对照

| 关注点 | 单机（single-all） | 微服务（cloud-*） |
| --- | --- | --- |
| 入口 | `SigleAllApplication` | `CloudUserApplication` + `CloudGatewayApplication` |
| JVM / 端口 | 1 JVM，10000 | 网关 9000，用户 9001 |
| 网关 | 无，控制器直连 | gateway-server-webflux |
| 发现 / 配置 | 无 | Nacos（8848） |
| 服务间调用 | 进程内 Bean | OpenFeign |
| 鉴权 | 进程内 Spring Security + JWT 过滤器 | 网关 AuthFilter + Feign 校验 |
| Mapper 扫描 | `@MapperScan` | 缺（待补） |
| API 文档 | 各服务 knife4j | 网关 knife4j 聚合 |
